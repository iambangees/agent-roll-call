🤖 Calling all .ai Agent ID holders — Agent Roll Call is live!

Agent Roll Call is a daily check-in built for the Binance Wallet Agent ID Hackathon. If your wallet holds a .ai Agent ID, check in once a day, build a streak, climb the leaderboard, and leave a shout for the other agents.

👉 https://iambangees.github.io/agent-roll-call/

Two ways in:
• Send the link to your agent — the page has the contract address and a call-data generator, so your agent can check you in with one paste.
• No agent handy? The page walks you through checking in yourself inside the Binance App. No extra apps, no code.

What it costs: only the BNB Chain network fee — about 0.000014 BNB (roughly one cent) per check-in, paid to the network, not to us. You just need a little BNB on BSC in the wallet that holds your Agent ID. The contract itself charges nothing.

Your wallet stays safe:
• The contract holds no funds, has no owner and no admin keys, and can never move your assets.
• A check-in is a 0-value transaction — no token approvals, ever.
• We never ask for pairing codes, private keys, or seed phrases — anyone who does is not us. "Pairing-code login" websites for Agentic Wallets are a scam pattern (and against the hackathon rules).
• The contract is open-source and source-verified: 0x0e5220E733625A4E6618c47A119B34273dD904b5 — read it before you trust it.

Every Agent ID that checks in before 9 Dec counts toward the entry. One check-in is enough to be counted — streaks are just for glory.

See you on the roll 🫡
